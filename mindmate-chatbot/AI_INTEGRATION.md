# AI Integration Guide

## Overview

MindMate uses a sophisticated three-tier response system to provide intelligent, safe, and reliable mental health support:

1. **Crisis Detection** (Highest Priority) - Runs before AI calls
2. **AI Response** - Calls OpenAI/Gemini API with conversation context
3. **Rule-based Fallback** - Used when AI fails or is unavailable

## Setup

### 1. Environment Variables

Copy `.env.local.example` to `.env.local` and add your API keys:

```bash
# OpenAI (Recommended)
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini

# Or Google Gemini
GOOGLE_GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-pro

# AI Configuration
AI_PROVIDER=openai
AI_MAX_TOKENS=500
AI_TEMPERATURE=0.7
MAX_CONTEXT_MESSAGES=10
```

### 2. Supported Providers

- **OpenAI** (Recommended): GPT-4o-mini, GPT-4, GPT-3.5-turbo
- **Google Gemini**: Gemini Pro, Gemini Pro Vision

## Architecture

### Response Flow

```
User Message
    ↓
Rate Limit Check
    ↓
Crisis Detection (Keywords: suicide, self-harm, etc.)
    ↓ (if no crisis)
AI API Call (with retry logic)
    ↓ (if AI fails)
Rule-based Fallback
    ↓
Response to User
```

### Crisis Detection

The system checks for crisis keywords **before** calling the AI:

- suicide, kill myself, end it all
- self-harm, hurt myself
- overdose, ending it
- no reason to live, better off dead

When detected, it immediately provides:
- Crisis hotline numbers (India: 14416, US: 988)
- Supportive message
- No AI call is made

### AI Response Generation

**System Prompt**: Configured with mental health protocols including:
- Emergency intervention guidelines
- Case-specific responses (anxiety, depression, academic stress, trauma)
- Tone and style guidelines (warm, non-judgmental, concise)

**Context Management**:
- Last 10 messages included in each request
- Automatic context window management
- Token counting to stay within limits

**Response Validation**:
- Sanitizes excessive whitespace
- Checks response length (10-2000 characters)
- Filters inappropriate content
- Validates response structure

### Error Handling

**Retry Logic**:
- Maximum 2 retries with exponential backoff
- Initial delay: 1 second
- Backoff multiplier: 2x
- Retryable errors: 429 (rate limit), 500, 503

**Timeout**:
- 30 seconds per request
- Automatic abort on timeout
- Falls back to rule-based responses

**Rate Limiting**:
- Client-side: 10 requests per minute
- Prevents API quota exhaustion
- Polite message to user when limit reached

### Fallback System

When AI fails, the system uses rule-based responses:

**Pattern Matching**:
- Anxiety/panic keywords → Breathing exercises
- Depression keywords → Validation + micro-steps
- Academic stress → Task breakdown
- Sleep issues → Sleep hygiene tips
- General support → Empathetic listening

## Usage

### Basic Integration

```typescript
import { getAIResponse } from '@/utils/aiService';

const response = await getAIResponse(userMessage, conversationHistory);

console.log(response.message);  // AI-generated response
console.log(response.source);   // 'ai' | 'crisis-protocol' | 'fallback' | 'rate-limit'
console.log(response.topics);   // ['anxiety', 'sleep']
console.log(response.sentiment); // 'positive' | 'neutral' | 'negative' | 'crisis'
```

### Response Sources

- `ai`: Successfully generated by AI model
- `crisis-protocol`: Crisis detected, emergency response
- `fallback`: AI failed, using rule-based response
- `rate-limit`: Too many requests, rate limit reached

## Cost Management

### Recommended Models

- **OpenAI GPT-4o-mini**: $0.15/1M input tokens, $0.60/1M output tokens
- **Google Gemini Pro**: Free tier available, then $0.50/1M tokens

### Token Optimization

- Max tokens per response: 500 (configurable)
- Context window: Last 10 messages only
- System prompt: ~400 tokens
- Average conversation: ~200 tokens per exchange

**Estimated Costs** (GPT-4o-mini):
- 100 conversations/day: ~$0.50/month
- 1,000 conversations/day: ~$5/month
- 10,000 conversations/day: ~$50/month

### Cost Reduction Tips

1. Use GPT-4o-mini instead of GPT-4 (10x cheaper)
2. Reduce MAX_CONTEXT_MESSAGES to 5-7
3. Lower AI_MAX_TOKENS to 300-400
4. Implement daily/monthly token limits
5. Cache common responses

## Privacy & Security

### Data Handling

- **No persistent storage**: Conversations not logged to disk
- **Session-based**: Uses session IDs, not user identifiers
- **API security**: API keys stored in environment variables
- **No PII**: System prompt instructs AI not to request personal info

### Best Practices

1. Never log full conversation content
2. Implement data retention policies
3. Provide clear privacy disclosures
4. Allow users to delete history
5. Use HTTPS for all API calls

## Troubleshooting

### "OpenAI API key not configured"

- Check `.env.local` file exists
- Verify `OPENAI_API_KEY` is set
- Restart dev server after adding keys

### "Request timed out"

- Check internet connection
- Verify API endpoint is accessible
- Consider increasing timeout (currently 30s)

### "Rate limit reached"

- Wait 60 seconds
- Reduce request frequency
- Check if API key has quota

### AI responses seem off-topic

- Review system prompt
- Check conversation context length
- Verify temperature setting (0.7 recommended)
