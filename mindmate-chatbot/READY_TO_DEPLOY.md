## 🚀 **Deploy in 3 Steps:**

### Step 1: Get Your Groq API Key (2 minutes)
1. Go to https://console.groq.com/keys
2. Sign up (free, no credit card)
3. Create API key
4. Copy it (starts with `gsk_...`)

### Step 2: Add API Key (30 seconds)
1. Open `mindmate-chatbot/.env.local`
2. Replace `your_groq_api_key_here` with your actual key:
   ```
   GROQ_API_KEY=gsk_your_actual_key_here
   ```
3. Save file

### Step 3: Deploy to Vercel (2 minutes)
1. **Push to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "MindMate AI chatbot with Android PWA"
   git remote add origin https://github.com/YOURUSERNAME/mindmate-chatbot.git
   git push -u origin main
   ```

2. **Deploy on Vercel:**
   - Go to https://vercel.com
   - Sign up with GitHub
   - Click "New Project"
   - Import your `mindmate-chatbot` repo
   - Click "Deploy"
   - Add environment variable: `GROQ_API_KEY` = your key
   - Redeploy
